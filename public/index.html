Chrome Extensions Ranking: user manual

A ranking of Google Chrome extensions built from Chrome Web Store snapshots. The store cannot sort by rating and popularity together; this page can, and it shows how positions changed since earlier snapshots.

Quick start

  • Pick a Category, a Price and a Sort by order. To search, type a phrase and press Enter or Search.
  • Click a row for details on the right. Double-click it (or press Go to extension page) to open it in the Chrome Web Store.
  • Choose Compare to to see how positions moved since an earlier snapshot.

Toolbar

CategoryOnly extensions from one store category.
Sort byRate * Rate users (default: well rated and by many people), User count, Rate, Rate * User count, Rate, User count.
PriceAny, Free, or Non-free (anything not plainly free, including in-app purchases).
Compare toThe earlier snapshot to compare with. Fills the Change column.
PhraseCase-insensitive text search in the field chosen under Search in (name, name+desc, desc, author). Clear resets it.

Columns

  • Change: ↑ n / ↓ n = positions gained or lost since the chosen snapshot, — = no change, NEW = not in that snapshot's ranking. Positions are counted within the same filtered list.
  • Rate is the average star rating, Rate users how many people rated, User count the installs reported by the store (rounded by the store).

Good to know

  • The table shows the top 500 matches; the status bar tells how many there are in total.
  • Included: extensions rated at least 3.00 by at least 10 people and used by at least 1,000 users. Themes and Chrome Apps are left out.
  • The data comes from snapshots (the date is in the title bar). A new one is added about once a year, so this is not live data.
